# Conventions

- Skill folder name = `<tech>-<topic>`, lowercase, hyphens. Must match `name` in the frontmatter.
- `description` states what the skill does and when to use it.
- Keep `SKILL.md` short; move heavy content to `references/`, `scripts/` or `assets/`.
- All scripts, comments and output messages are in English.
- One skill = one responsibility.
- Commits follow Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`).
